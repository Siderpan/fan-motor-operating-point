# 風扇馬達操作點

風扇馬達設計用的單頁工具：由風扇 RD 提供的目標靜壓 P、風量 Q，換算馬達需要的轉速 N 與轉矩 T，並檢查驅動電壓、相電流、Ke 可行範圍與系統效率。

## 功能

1. **目標操作點**：輸入 P、Q、空氣密度與軸承摩擦轉矩。
2. **由 P、Q 求 N、T**：以參考 PQ 曲線（風扇定律 + 系統阻抗相似點）或靜壓效率估算。
3. **馬達與驅動**：方波 120° / 正弦 SVPWM 電壓檢查、熱態電阻、磁鐵溫度修正、電感與換相檢查。
4. **轉速換算**：已知一組 N、Q、P、T，推算其他轉速的 Q、P、T 與電壓裕度，也可反推轉速。

所有單位皆可切換（預設 SI）。

## 使用

直接開啟 `index.html`，或透過 GitHub Pages 瀏覽。單一 HTML 檔，不需安裝或建置。

## 資料

輸入的參數只存在使用者自己瀏覽器的 localStorage，不會上傳到任何伺服器，其他使用者也看不到。
